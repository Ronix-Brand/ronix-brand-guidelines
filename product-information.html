Ronix. Design System — User Interface

Ronix Design System  /  Components  /  Product information

Product information

The product detail page — the deepest screen in the system. An image slider paired with an information wrapper, followed by a sticky tab bar and an information section carrying the feature list and specification table.

Page layout

Two columns above the fold: the slider takes roughly 60 % of the container and the information wrapper the rest. Below 992 px they stack, slider first.

The information wrapper is a fixed 512 px at its Default size and compresses to 434 px inside the 1320 and 1140 containers.

Vertical order

  • Main navigation bar — 54 px
  • Slider and information wrapper
  • Sticky tablist — 64 px container, 40 px buttons
  • Information Section — feature list and spec table

Image slider

A square stage with a thumbnail rail. The rail runs vertically at 75 px beside the stage on large viewports, and horizontally at 65–90 px beneath it on smaller ones.

Video thumbnails

A video thumbnail carries a play badge — a filled circle in brand red, centred on the tile.

Chevrons

Two 30×30 chevrons sit inside the stage at its lower-left, stacked vertically — they page the thumbnail rail, not the stage.

Up to nine thumbnails are shown at every size. At narrow widths nine tiles exceed the frame, so the rail scrolls rather than wrapping — keeping the stage in a fixed position while the thumbnails move.

Information wrapper

The densest block of type in the system — eleven distinct elements in a single column, using six different type styles.

Order

  • Product rate — star plus count, Caption 1
  • Labels — the product-card status chips, reused
  • Item code — Title 5
  • Barcodes — three Caption 1 lines
  • Origin badge — image
  • Product name — Title 2 in-container, 28/32
  • Description — Body 1, 16/20
  • Actions — Bulk order (primary), Compare (secondary)
  • Feature and Spec accordions
  • Share — social icons
  • Similar models — chips

Sticky tablist

Six buttons in a 64 px container beneath the fold. The library annotates two frames with “While Scrolling : Tabs Sticky” — the bar pins under the navigation as the page scrolls.

Buttons are 40 px tall at Large and 36 px at Medium and Small, matching the standard button component rather than defining their own.

At 358 px the six buttons need 874 px against a 326 px container, so the bar scrolls horizontally.

Information Section

Two columns on one white surface: the feature list on the left, the specification table on the right, with a pair of document actions beneath.

Feature items are Body 2 Strong — Medium 500 at 14/18. The spec table uses the same size, with labels in regular weight and values in Foreground/2.

It ships in seven variants across three Size values and seven Breakpoints — the most heavily specified component on the page.

Markup

The accordions are native <details> elements — they work without JavaScript and are keyboard accessible by default.
